# Project Overlay Model

Project repositories should consume personal governance output instead of redefining the personal marketplace.

Use project-local overlays only for:

- project-only allowlists
- precedence rules
- project-scoped skills
- project activation constraints
- additional review gates that are specific to one codebase

The personal `agent-governance` repo remains the canonical source for shared capabilities, runtime adapters, machine profiles, and lock history.

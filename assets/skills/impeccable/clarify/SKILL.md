# Clarify UX Copy

Improve the requested interface text without expanding into a design-system or product-flow rewrite.

## Decide from context

Identify the audience, current screen/action, user state, desired next action, terminology already used, and any space or localization constraint. Read existing nearby copy before inventing a new voice. Ask only when a missing answer would materially change the result.

## Rewrite

- Preserve accurate product meaning and established terms.
- Lead with what happened or what the user can do next.
- Use specific action labels instead of `OK`, `Submit`, or `Click here` when the action is known.
- For errors, state the problem in plain language and provide a safe recovery step when one exists.
- For destructive confirmation, name the object, consequence, and irreversible boundary.
- Keep labels and help text distinct; do not repeat visible information.

Do not add unsupported promises, blame the user, expose internal error codes as the main message, use humor in failure states, or vary terminology for style.

## Verify

Check comprehension, actionability, brevity, terminology consistency, tone, localization, and factual accuracy. For a small edit, return only the revised copy and any material assumption; do not manufacture a lengthy UX audit.
